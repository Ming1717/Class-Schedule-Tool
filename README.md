# Class-Schedule-Tool

\# 课表解析与空闲时段计算



\## 项目简介

这是一个用于解析课表并计算空闲时段的小工具，支持多人的共同空闲时间计算。



\## 功能说明

\- \*\*需求1：读入课表\*\*  

&#x20; 支持从 CSV 文件读取课程信息（课程名、星期几、开始时间、结束时间），并打印出文本视图。

\- \*\*需求2：算空闲时段\*\*  

&#x20; 给定每天的可用时间范围（08:00-22:00），自动计算每天的空闲时段，并合并连续或重叠的时间碎片。

\- \*\*需求3：找共同空闲时间\*\*  

&#x20; 输入多个人的课表，计算所有人的共同空闲时段，并按空闲时间从长到短排序输出。
